===============================================================================
               MICROSOFT PLUS! 98 FOR LINUX TERMINAL (SIMULATION)
===============================================================================

Bienvenido al CD de instalación de componentes de Plus! 98 para terminal.

Este disco virtual contiene los scripts de ejecución y configuración de los
temas visuales reconstruidos mediante código Python nativo y ncurses.

CONTENIDO DEL DISCO:
- /src          : Módulos de animación en código fuente.
- /cdrom/SOUNDS : Soplos de audio sintetizados usando el altavoz/chime del sistema.
- /cdrom/THEMES : Esquemas de color y variables de configuración estilo .theme.
